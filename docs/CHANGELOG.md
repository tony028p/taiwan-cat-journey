# 版本紀錄 Changelog

## v4.2
- **身體比例**：走路、跑步時身體中段不再細瘦。肚子改成一條接近水平、在後腿前微微下垂的線，只往胸口加深，不再收細腰；身體整體降低約 12%，腿的骨架等比例縮短，肚子到地面的高度和身體厚度接近（參考貓的解剖：胸口底部約在手肘高度，家貓腿相對身體偏短）。
- **頭與眼睛縮小**：頭縮小約 23%（身體長度約為頭長的 2.4 倍；真實的貓約 4 倍，Q 版約 1.5 倍），眼睛再縮小約 16%（眼高約為頭高的 0.28），整體更優雅，表情仍看得清楚。
- **耳朵**：耳尖降低約 35%（耳高約為頭骨高度的 0.4，接近真實的貓），尖端修圓；頭轉到 3/4 時，後側的耳朵不再變成細長尖刺。
- 背上的亮面改成三層漸淡，不再有一條硬邊；背中線的條紋順著背部曲線；臀部後緣更圓，腿稍微加粗。

## v4.1
- **更可愛的頭與一致的配色**：頭部外框改成一條平滑的輪廓（不再是幾個圓拼起來而凹凸不平），頭和眼睛都放大；前腳從肩膀到腳掌同一個顏色，下巴到胸口是一整片奶油色圍兜。
- **後腳輪廓**：臀部到腳跟改成一條連續外凸的線，不再在大腿後方凹進去；前腳、後腳和身體相接處的內線完全拿掉。
- **新動作**：「折手手」的香箱坐（前腳收在胸口下，七美和三花一起趴、結尾睡覺）；用舌頭梳理身體（頭轉向後方舔側腹：阿里山、日月潭、勝興車站）。
- **後腳再修正**：大腿短而寬、膝蓋收在臀部下，小腿變短、跗關節抬高到約三分之一腿高，腳掌以下近乎垂直，不再像鳥腿。頭貼近肩膀，脖子不再細長。臉頰的毛簇移除，口鼻變小，側面不再有凸出的一塊。
- **頭可以轉向鏡頭**：頭部改成小型 3D 模型（頭骨、臉頰毛、口鼻、下巴、耳朵），可以從側面平順轉到正面；所有表情在側面、3/4、正面都能用。在醒來、坐上繫船柱、蝴蝶停鼻子、被汽笛嚇到後、吐舌、打噴嚏、眼睛反光、搭火車與飛機看窗外、快到家時看向鏡頭。
- **身體更自然**：軀幹縮短約 14%，胸口深、腰身收、臀部圓；後腳移到臀部下方；腿與尾巴更細，頭更大、脖子更細。
- **前腳接身體的線條拿掉**：內線只留在近側腳和遠側腳交疊的地方。

## v4（3:51）
- **貓咪配色**：肚子、胸口、腳掌改成奶油色；遠側的腳深一階，近側的腳畫在獨立圖層，只在和身體外緣、遠側腳重疊處加細內線，四條腳不再糊成一團。
- **後腿不再像雞腿**：大腿不再是獨立的條紋橢圓，臀部併入身體輪廓，上臂和大腿跟身體一起上色，只有細長的小腿從身體下方長出來；腹部的奶油色在臀部前收掉。
- **走路與奔跑**：走路時肩胛骨、骨盆依承重腳起伏，頭部反向微動；奔跑改成橫向襲步，脊椎長度只變化約 11%（原本拉長約 70%），奔跑速度提高。
- **表情系統**：眼睛開合、笑眼、眼皮角度、瞳孔大小與視線、耳朵（含飛機耳）、嘴型（喵、微笑、皺眉、吐舌）、鬍鬚、腮紅、夜間眼睛反光，共 12 種預設表情；另有「！ ？ Z ♪ ♥ 汗滴 閃光」漫畫符號。
- **與場景互動**：每個景點都改成 3–5 個段落的小故事，配合字幕，例如：九份拍水窪裡的燈籠倒影、基隆撲海鷗失敗後跳上繫船柱、蝴蝶停在鼻子上、蓮池潭鯉魚跳出水面、扇形車庫汽笛嚇得炸毛、桐花掉在鼻子上打噴嚏、柿子滾過來拍一下、東門城機車燈照出眼睛反光、機場跳上圍欄看飛機、金門學風獅爺吼再跳上石座。沿途轉場也都加上表情。
- **旅途上的朋友**：新增黑貓、白貓、灰虎斑、三花、賓士貓五種毛色。九份和躲雨的黑貓一起看燈籠倒影；伯朗大道租借腳踏車旁的白貓一起撲蝴蝶撞鼻子；鵝鑾鼻和灰貓並肩看夕陽；七美和三花依偎看雙心石滬；檜意森活村和午睡的賓士貓碰鼻子；高美濕地有散步的同伴；桃園機場和看飛機的貓坐在圍欄上；馬祖和朋友輪流點亮藍眼淚；外澳海上有衝浪貓、天上有飛行傘貓。結尾睡著時，夢裡出現一路上的朋友，並加上一句字幕。互動依各地遊客最常做的事安排（騎腳踏車、看夕陽、情侶拍照、看飛機、踏浪追藍眼淚、衝浪、飛行傘）。
- **WebGL 特效**（`src/gl.js`）：泛光與光暈、朝太陽方向的光線散射、調色、紙張紋理、暗角、顆粒，以及水面倒影的波紋；沒有 WebGL 時自動退回原本的 Canvas 版本。
- 新工具 `tools/posesheet.cjs`：一次輸出步態、姿勢、表情對照圖。
